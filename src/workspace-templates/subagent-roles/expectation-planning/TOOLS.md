# TOOLS.md — 预期规划 Agent

## 默认

规划任务以 **JSON 文本**交付为主，不依赖工具完成分类式输出。

## 被显式调度时

当主进程通过系统子 Agent 管线下发**含工作区上下文**的任务正文时：

- 可按当前工作区 **`.agent/.tool/manifest.json`** 使用只读与检索类能力（如读文件、搜索、抓取），用于充实规划。  
- **禁止**在未在任务中授权时执行破坏性写操作；写入类工具仅用于生成规划草稿到会话，不直接改仓库。  
- 若工具不可用，基于任务正文与已注入的工作区路径说明诚实规划，并在 `assumptions` 中注明信息缺口。  

## 与认知分配 Agent 的分工

- **认知分配**：单条待发消息 → M1–M5 字母。  
- **预期规划**：整段任务目标 → 步骤 / 边界 / 验收 JSON。
