## ClawFlow HTML 原型（静态可点击）

### 打开方式

- 直接用浏览器打开 `prototype/index.html`（推荐 Chrome / Edge）。
- 若部分交互（如 `fetch`）被浏览器限制，可用本地静态服务器，但本原型不依赖网络与构建步骤。

### 覆盖范围

- 主导航：Dashboard / Chat / Skills / Connectors / Settings
- 关键弹窗/抽屉：连接器新增/编辑抽屉、删除确认弹窗
- 状态：空状态 / 加载骨架 / 错误提示 / Toast

### 设计主题

- 极简深色：灰底 + 暗绿主操作 + 暗金强调状态
