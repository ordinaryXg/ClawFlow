## 2. 工作区

### 2.1 注册与切换

- 用户从侧栏 **添加文件夹** 或 **新建工作区**（`workspace:pickFolder`、`workspace:addFromAbsolutePath`、`WorkspaceCreateModal`）。
- **不**在应用启动时自动 `setActive`；最近列表在 `userData/cf.workspace.v1.json`。
- 切换工作区：渲染 `workspace:setActive` → 主进程 `applyActiveWorkspace`（注册表 + `syncActiveWorkspaceRootToEngine`）；引擎内部 `setWorkspaceRoot`。
- 证据：`workspace-ipc.ts`、`active-workspace-sync.ts`、`workspaceStore.ts`、`WorkspaceSidebar.tsx`。

### 2.2 初始化 bundle

打开/激活工作区时主进程确保：

| 动作 | 证据 |
|------|------|
| `.agent/.tool/manifest.json` + 说明 md | `ensureWorkspaceToolBundle()` |
| 角色模板 `.agent/.roleAgent/` | `workspace-agent-bootstrap.ts` |
| Hermes `skill-creator` v2 整包 | `workspace-hermes-skill-bootstrap.ts` |
| 主记忆模板 `.agent/.memory/` | `workspace-main-memory-bootstrap.ts` |
| 迁移旧版 `.tool` → `.agent/.tool` | `migrateLegacyWorkspaceAgentBundleSync` |
| 清理遗留 `.subagent/` | `workspace-legacy-subagent-cleanup.ts` |

### 2.3 工具能力开关（Manifest）

- 路径：`${WORKSPACE}/.agent/.tool/manifest.json`（version 2）。
- 能力 ID：`src/shared/workspace-tools.ts`（9 项，含 `skills`、`knowledge_base`）。
- 设置 **account** 可勾选；新建工作区默认 `skills`、`knowledge_base` 常为 true。
- 治理：发模型前过滤 schema；执行时二次校验（`tool-runtime-core.ts`、`clawflow-engine.ts`）。

### 2.4 Git 与缓存

- 侧栏 Pull / Push（`workspace:gitPull`、`workspace:gitPush`）。
- **重置工作区缓存**：删 `.agent/`、blob 等，**保留** `.clawflow-data/` 待办。

### 2.5 资源管理器（右栏 / IPC）

- 列目录、读预览、解析路径、mkdir/rename/delete 等（`workspace:*`）。
- 变更日志：`workspace:getChangeLog` → ChatRightTabs `changes`。
- 聊天拖放：`workspace:copyChatDropFiles`（主进程尽早注册）。

## 3. 对话与引擎

### 3.1 聊天传输（渲染 → 引擎）

| 路径 | 何时 | 实现 |
|------|------|------|
| **主路径** | Electron 且具备 `engineGateway*` | `chat-gateway-client.ts` → `ws://127.0.0.1:<port>/ws`（`chat:send` / `chat:delta` / `chat:final`） |
| **回退** | 无 WebSocket 或 Gateway IPC | `engine:sendMessage`（`chatStore` 非流式 + 前端 reveal） |

- 会话 CRUD：`engine:getConversations`、`upsertConversation`、`deleteConversation`。
- **未用于聊天 UI**：`engine:sendMessageStream`、`engine:chatStream`（`engine-ipc.ts` 仍注册，无渲染层 `onEngineChatStream` 订阅）。
- 证据：`chatStore.ts`、`gateway-daemon.ts`、`AGENTS.md`「聊天传输」。

### 3.2 对话模式

| 模式 | 含义 |
|------|------|
| `ask` | 问答，少工具 |
| `plan` | 规划向 |
| `multitask` | 多步工具执行 |

可由认知分配建议或用户选择。

### 3.3 发送前系统 Agent

| 功能 | 触发 | IPC / 模块 |
|------|------|------------|
| 认知分配 | 发送前（可关） | `systemAgents:classifyConversation` |
| 预期规划 | `needsExpectationPlanning` | `systemAgents:planExpectation` + `systemAgents:expectationPlanDelta` |

设置：`SystemAgentsSettingsPanel`（`agents`）。

### 3.4 Tool Loop 与审批

- `tool_calls` → `ToolRuntime.executeToolCalls` → 回注 → 循环至文本或达上限。
- 运行时：最大轮次、出站合并窗口（`engine:getRuntimeSettings`、`system`）。
- **工具审批（UI）**：Gateway 推送 `chat:toolApproval` → `ToolApprovalBar` → `chat:toolApprovalResponse`（WS）。
- **引擎侧**：`engine:resolveToolApproval` / `ClawFlowEngine.resolveToolApproval` 供 Gateway 守护进程与 IPC 直连场景。

### 3.5 上下文与模型

- 模型：`engine:getChatModels`；鉴权：`engineAuth:*`。
- 下一请求上下文：`engine:estimateNextRequestContext` + `ContextUsageRing`（`next-request-context.ts`、`context-saturation.ts`）；可选分段 `segments`。
- Web 搜索：设置 + 工具 `web_search`（`engine/web-search.ts`）。

## 4. 模型工具（按能力域）

> 注册入口：`createDefaultToolRuntime()` → `tool-runtime-default-tools.ts`（类在 `tool-runtime-core.ts`）。共 **36** 个 `function.name`（2025-05 代码快照）。

`workspace_git_status`、`workspace_git_diff`、`workspace_git_log`

### 4.4 搜索与爬取（manifest: `web_search` / `web_scrape`）

| 工具 | 说明 |
|------|------|
| `web_search` | 可配置 Provider |
| `web_scrape` | HTTP → `${WORKSPACE}/.agent/.clawflow/scrapes/` |

另：`workspace_rg_search`（工作区内 ripgrep）。

### 4.5 待办（manifest: `todos`）

`workspace_todo_list`、`workspace_todo_create`、`workspace_todo_update`、`workspace_todo_remove`

- 数据：`.clawflow-data/todo-triggers.v1.json`。
- 调度：`todo-triggers-scheduler.ts`；UI：`TodoTriggersPanel`；IPC：`todoTriggers:*`。

### 4.6 Hermes 技能（manifest: `skills`）

### 4.7 Hermes 记忆与检索（manifest: `skills` / `knowledge_base`）

| 工具 | 说明 |
|------|------|
| **`hermes_search`** | **推荐**：FTS，Markdown 命中 |
| `hermes_memory_upsert` | 写入/更新记忆文档 |

- DB：`.agent/.clawflow/hermes-memory.db`（`hermes-memory-db.ts`）。
- 设置 **memory**：`memoryFts:search`、`memoryFts:rebuild`。

### 4.8 知识库（manifest: `knowledge_base`）

- **Phase 1（已落地）**：索引 `.agent/.memory/`、`.agent/.knowledge/**`、`.agent/.skills/**`；清单 `knowledge-manifest.json`；Hub `KnowledgeBaseHubPanel`（检索、新建笔记、列表）；IPC `knowledge:listManifest`、`knowledge:createNote`、`knowledge:ingestFile`。
- **Phase 2+（未做）**：向量索引、PDF 深度摄入管线。

### 4.9 其他

- `get_date`、`workspace_feishu_invoke`（manifest 外或按域映射，见 bridge）。

### 4.10 已移除

- `workspace_subagent_*`、OpenClaw 技能市场相关工具。

## 5. 系统子 Agent（应用级）

存储于应用缓存 `system/`，不写入用户 Git 仓库。

| 槽位 | 功能 | 调度 |
|------|------|------|
| `cf-cognitive-allocation` | M1–M5 → ask/plan/multitask | 每次发送前（可关） |

## 6. 集成与基础设施

### 6.1 Gateway

- HTTP + WebSocket（默认 **18789**）。
- IPC：`engineGateway:status|start|stop|restart|logs`。
- UI：`gatewayStore`、设置 **integrations**。
- 聊天：**必须**先 `engineGatewayStart` 再连 WS（`chat-gateway-client.ts`）。

### 6.2 飞书

- `messaging:*` IPC；入站 `feishu-event-server.ts`。
- 桥接工作区会话；`chat:conversationsDirty`。

### 6.3 应用缓存与 Launcher Stash

- 缓存根：设置 **system**；`${AppCache}/workspaces/<hash>/.clawflow-launcher-stash/`。
- `app:sweepLauncherStash`。

### 6.4 国际化与主题

- `i18next` + `locales/*`；`app:setLanguage` ↔ 应用菜单。
