## 2. 工作区

### 2.1 注册与切换

- 用户从侧栏 **添加文件夹** 或 **新建工作区**（`workspace:pickFolder`、`workspace:addFromAbsolutePath`、`WorkspaceCreateModal`）。
- **不**在应用启动时自动 `setActive`；最近列表持久化在 `userData/cf.workspace.v1.json`。
- 切换工作区：同步引擎根 `engine:setWorkspaceRoot`、刷新会话与 Hub 状态。
- 证据：`workspace-service.ts`、`WorkspaceSidebar.tsx`、`workspaceStore.ts`。

### 2.2 初始化 bundle

打开/激活工作区时主进程确保：

| 动作 | 证据 |
|------|------|
| `.agent/.tool/manifest.json` + 说明 md | `ensureWorkspaceToolBundle()` |
| 角色模板 `.agent/.roleAgent/` | `workspace-agent-bootstrap.ts` |
| Hermes `skill-creator`（包：SKILL + templates/examples/scripts） | `workspace-hermes-skill-bootstrap.ts`、`skill-creator-template-bundle.ts` |
| 主记忆模板 `.agent/.memory/` | `workspace-main-memory-bootstrap.ts` |
| 迁移旧版 `.tool` → `.agent/.tool` | `migrateLegacyWorkspaceAgentBundleSync` |
| 删除遗留 `.subagent/`、旧 sub-agents json | `workspace-legacy-subagent-cleanup.ts` |

### 2.3 工具能力开关（Manifest）

- 路径：`${WORKSPACE}/.agent/.tool/manifest.json`（version 2）。
- 能力 ID：见 `src/shared/workspace-tools.ts`（9 项，含 `skills`、`knowledge_base`）。
- 设置页 **account** 区可勾选；新建工作区默认 `skills: true`，`knowledge_base: true`。
- 治理：发模型前过滤 schema；执行时二次校验（`tool-runtime.ts`、`clawflow-engine.ts`）。

### 2.4 Git 与缓存

- 侧栏 **Pull / Push**（`workspace:gitPull`、`workspace:gitPush`）。
- **重置工作区缓存**：删除 `.agent/`、blob、遗留目录，**保留** `.clawflow-data/` 待办（`removeWorkspaceManagedMetadataDirs`）。

### 2.5 资源管理器（右栏 / IPC）

- 列目录、读预览、解析绝对路径、在资源管理器中显示、mkdir/rename/delete。
- 变更日志：`workspace:getChangeLog` → `ChatRightTabs` changes。
- 聊天拖入外部文件：`workspace:copyChatDropFiles`。

## 3. 对话与引擎

### 3.1 会话

- 按工作区隔离会话列表；CRUD 经 `engine:getConversations`、`upsertConversation`、`deleteConversation`。
- 流式发送：`engine:sendMessageStream` + 事件 `engine:chatStream`。
- 证据：`clawflow-engine.ts`、`chatStore.ts`。

### 3.2 对话模式

| 模式 | 含义 |
|------|------|
| `ask` | 问答，少工具 |
| `plan` | 规划向 |
| `multitask` | 多步工具执行 |

可由 **认知分配** 建议或用户选择（`chatStore` `mode` 字段）。

### 3.3 发送前系统 Agent

| 功能 | 触发 | IPC / 模块 |
|------|------|------------|
| 认知分配 | 发送前（可配置） | `systemAgents:classifyConversation` → `cognitive-allocation-agent.ts` |
| 预期规划 | 复杂任务（`needsExpectationPlanning`） | `systemAgents:planExpectation` + delta 事件 → `expectation-planning-agent.ts` |

设置：`SystemAgentsSettingsPanel`（`settings` → `agents`）。

### 3.4 Tool Loop 与审批

- 模型返回 `tool_calls` → `ToolRuntime.executeToolCalls` → 结果回注 → 循环直至文本回复或达上限。
- 运行时设置：最大轮次、出站合并窗口等（`engine:getRuntimeSettings`、`settings` → `system`）。
- **工具审批**：高风险调用挂起 `ToolApprovalBar`，用户 `engine:resolveToolApproval` 后继续。

### 3.5 上下文与模型

- 模型目录：`engine:getChatModels`；鉴权：`engineAuth:*` profiles。
- 上下文饱和度：`engine:estimateNextTurnContext` + UI 环（`context-saturation.ts`）。
- Web 搜索：独立设置（Provider、API Key），工具 `web_search`（`engine/web-search.ts`）。

## 4. 模型工具（按能力域）

### 4.1 文档与文件（manifest: `docs`）

`workspace_list_dir`、`workspace_read_file_preview`、`workspace_read_file`、`workspace_write_file`、`workspace_apply_patch`、`workspace_apply_patch_v2`、`workspace_mkdir`、`workspace_rename_path`、`workspace_delete_path`、`workspace_rollback_op`

### 4.2 Shell（manifest: `shell`）

`workspace_run_shell`、`workspace_run_tsc_no_emit` — 实现见 `workspace-shell-exec.ts`（工作区根内、策略限制）。

### 4.3 Git（manifest: `git`）

`workspace_git_status`、`workspace_git_diff`、`workspace_git_log`

### 4.4 搜索与爬取（manifest: `web_search` / `web_scrape`）

| 工具 | 说明 |
|------|------|
| `web_search` | 可配置 Provider（Brave 等），设置页配置 |
| `web_scrape` | HTTP 拉取 → 纯文本 → `${WORKSPACE}/.agent/.clawflow/scrapes/<id>.md` |

### 4.5 待办（manifest: `todos`）

| 工具 | 说明 |
|------|------|
| `workspace_todo_list` | 列出触发器 |
| `workspace_todo_create` | 创建 |
| `workspace_todo_update` | 更新 |
| `workspace_todo_remove` | 删除 |

- 数据：`${WORKSPACE}/.clawflow-data/`（`WORKSPACE_TODO_DATA_DIR`）。
- 调度：`todo-triggers-scheduler.ts`；UI：`TodoTriggersPanel`；IPC：`todoTriggers:*`。
- 到点：`todo-trigger:fired`，可选 `submitToModel`。

### 4.6 Hermes 技能（manifest: `skills`）

| 工具 | 说明 |
|------|------|
| `workspace_skill_list` | 列出 `.agent/.skills/` |
| `workspace_skill_view` | 读技能文件 |
| `workspace_skill_create` / `patch` / `write_aux` / `delete` | 增删改 |

- UI：`SkillsPage`、`SkillsHubPanel`；IPC：`workspaceSkills:*`。
- **新建工作区**（尚无 `.agent/`）时安装 `skill-creator` v2 整包；既有工作区不自动补写。

### 4.7 Hermes 记忆

| 工具 | 说明 |
|------|------|
| `workspace_memory_search` | FTS 检索 |
| `workspace_memory_rebuild_index` | 重建索引 |

- DB：`.agent/.clawflow/hermes-memory.db`（`hermes-memory-db.ts`）。
- 设置页 **memory**：`memoryFts:search`、`memoryFts:rebuild`。

### 4.8 知识库（manifest: `knowledge_base`）

| 工具 | 说明 |
|------|------|
| `workspace_knowledge_query` | 面向模型的 Markdown 命中列表（含 L0 摘要） |
| `workspace_memory_search` | JSON 命中（含 rank、abstract） |
| `workspace_memory_rebuild_index` | 全量重建 FTS |

- 索引范围：`.agent/.memory/`、`.agent/.knowledge/**`（`.md`/`.txt`）、`.agent/.skills/**`。
- 清单：`.agent/.knowledge/knowledge-manifest.json`（扫描 `.knowledge/` 生成）。
- 技能名册：`.agent/.skills/skillManifest.json`（与 `.tool` 分离，避免与 manifest 开关混淆）。
- Hub：`KnowledgeBaseHubPanel` — 检索、新建笔记、文件列表（Phase 1）；PDF 摄入与向量检索为 Phase 2+。

### 4.9 已移除的工具能力

- `workspace_subagent_*` — 工作区委派子 Agent 已移除。
- `openclaw_skills_list` 及 OpenClaw 技能市场 IPC — 已移除；由 Hermes 工作区技能替代。

## 5. 系统子 Agent（应用级）

存储于应用缓存 `system/`，**不**写入用户 Git 仓库。

| 槽位 | 功能 | 调度 |
|------|------|------|
| `cf-cognitive-allocation` | M1–M5 分类 → 建议 ask/plan/multitask | 每次发送前（可关） |
| `cf-expectation-planning` | 生成任务规划 Markdown | 满足复杂度启发式时 |
| `cf-skill-agent` | 技能进化、维护 | `skill-evolution-scheduler.ts`（轮次阈值） |

管理：设置 → **agents**；IPC：`systemAgents:getOverview`、`saveSettings`、`saveSlots`、`reloadRoster`。

## 6. 集成与基础设施

### 6.1 Gateway

- 本地 HTTP + WebSocket 守护（默认端口 **18789**）。
- IPC：`engineGateway:status|start|stop|restart|logs`。
- UI：设置 → **integrations**。

### 6.2 飞书

- 配置多 Bot、测试 token、发送消息（`messaging:*` IPC）。
- 长连接入站：`feishu-event-server.ts`（`@larksuiteoapi/node-sdk`）。
- **桥接**：入站消息写入指定工作区会话（`chat:conversationsDirty` 跨工作区提示）。

### 6.3 应用缓存与 Launcher Stash

- 自定义缓存根：设置 → **system** → 应用缓存目录。
- `${AppCache}/workspaces/<sha256>/.clawflow-launcher-stash/`：聊天拖放等大文件暂存，**不**进 Git。
- `app:sweepLauncherStash` 清扫。

### 6.4 国际化与主题

- `i18next` + `locales/zh.json`、`en.json`。
- 主题/字号/关闭按钮：`settingsStore` + `I18nThemeBootstrap`。
- 菜单语言：`application-menu.ts` ↔ `app:setLanguage`。
