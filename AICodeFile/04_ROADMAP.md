# ClawFlow 路线图（Milestones / AI 可读）

> 本文件是“里程碑视图”，只描述**要达成什么**与**完成标准**，不写实现细节。实现细节与子任务在 `06_TASKS.md`。

## 里程碑 M0：可运行的开发环境（基础工程可用）

- **完成标准**
  - 能在开发模式启动 Electron（`npm run start`）
  - 能看到主页面且 IPC 调用不报错
  - 文档/脚本不依赖硬编码路径（统一 `${REPO_ROOT}`）

## 里程碑 M1（P0）：核心闭环可用（对话 + 基础管理）

- **范围**
  - 对话（含流式响应呈现、会话管理、历史持久化策略明确）
  - 技能管理（浏览/安装/启用/禁用）
  - 连接器管理（增删改/测试连接、敏感字段脱敏展示）
  - Gateway 状态（查询/启停/状态刷新）
- **完成标准**
  - 关键路径可手动验证通过（见任务清单中的验收）
  - UI 错误提示友好且可恢复

## 里程碑 M2（P1）：可配置与可维护（设置 + 稳定性）

- **范围**
  - 设置页：语言（zh/en）、主题（light/dark）、日志级别、OpenClaw 路径/超时等
  - 错误边界、加载态、空状态一致化
  - IPC 与 OpenClaw 交互的稳定性（启停确认、状态一致性策略）
- **完成标准**
  - 设置切换立即生效且持久化策略明确
  - 关键错误可复现可定位（日志/错误码/用户提示）

## 里程碑 M3（P2）：质量保障（测试 + CI）

- **范围**
  - 最小单测/集成测试覆盖关键模块
  - 最小 CI：lint + typecheck + build（至少在 Windows）
- **完成标准**
  - CI 通过且能阻断明显回归

## 里程碑 M4（P1/P2）：发布准备（打包/制品/更新）

- **范围**
  - `npm run make` 产物可用
  - 关键配置（asar、fuses、makers）明确
  - 可选：签名、自动更新
- **完成标准**
  - 打包产物在干净环境可运行，OpenClaw 集成可用或有降级提示
